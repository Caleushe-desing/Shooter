# Súper Salto

Platformer original de 8 bits con **4 mundos** y **16 niveles**. El héroe es **Caleo**, un personaje propio: no usa nombres, sprites ni música de Nintendo.

Abre `index.html` en el navegador (o sirve la carpeta con cualquier servidor estático).

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Cómo jugar

| Tecla | Acción |
| --- | --- |
| ← → o A D | Mover |
| Z, Espacio o ↑ | Saltar (mantener para saltar más alto) |
| X o Shift | Correr |
| C o Ctrl | Disparar (con flor de fuego) |
| ↓ | Agacharse (cuando Caleo es grande) |
| Enter | Confirmar |
| Esc o P | Pausa |
| M | Silenciar audio |

En móvil aparecen botones táctiles.

## Mundos

1. **Pradera Verde** — colinas, tuberías y el tutorial
2. **Desierto Ardiente** — dunas, pirámides y fosos
3. **Islas del Cielo** — nubes y enemigos voladores
4. **Reino Oscuro** — fantasmas, magma y el Duque Magma

Cada mundo tiene 4 niveles (el último es un fortín). El progreso se guarda en el navegador.

## Mecánicas

- Monedas, ladrillos y bloques `?`
- Honguito, flor de fuego, estrella y 1-UP
- Honguitos, caparazones, plantas, voladores y fantasmas
- Bandera al final de cada curso
- Vidas, tiempo y mapa del reino

Juego original inspirado en los platformers clásicos. No está afiliado a Nintendo.
