# AIM 3P — Laboratorio de puntería

Trainer **tipo Aim Lab** en **tercera persona**: ves al operador, apuntás con la mira y entrenás flick / tracking.

## Demo

Pedí el link al agente (túnel Cloudflare). En celular: stick + arrastrá + DISPARO.

## Jugar

```bash
npm install
npm run dev
```

## Modos

| Modo | Qué entrena |
|------|-------------|
| **GRIDSHOT** | 3 orbes en la pared. Flick rápido. |
| **FLICK** | 1 orbe que salta lejos. |
| **TRACKING** | Orbe en movimiento. Mantené la mira. |

Ronda de **60 segundos**. Puntos, precisión, aciertos.

## Controles

| Acción | PC | Celular |
|--------|----|---------|
| Mirar | Mouse (click para lock) | Arrastrá el lado derecho |
| Mover | WASD / flechas | Stick izquierdo |
| Disparar | Click / Espacio | Botón DISPARO (mantener) |
