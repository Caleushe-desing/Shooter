# GSLSGA — Escuadrón Neón

Shooter arcade **estilo Galaga**: formación, picados, rayo tractor y nave dual. Look **80s neón**, listo para PC y celular.

## Jugar

```bash
npm install
npm run dev
```

Abre la URL de Vite (por defecto `http://127.0.0.1:5173`).

## Controles

| Acción | PC | Celular |
|--------|----|---------|
| Mover | A D / ← → | Arrastrá el dedo |
| Disparar | Z / Espacio / Ctrl (mantener) | Automático al tocar |
| Pausa | P / Esc | — |
| Silencio | M | — |

## Objetivo

- Derribá el enjambre: **zánganos**, **polillas** y **comandantes**.
- En picado valen más puntos.
- El comandante puede **capturarte** con el rayo. Disparale para rescatar la nave y armar la **nave dual**.
- Cada 3 etapas hay un **Desafío**: nadie dispara de vuelta; si no se escapa ninguno, bonus **+10000**.
- Nave extra a 20.000 y 70.000 puntos.

## Look 80s

- Naves vectoriales neón
- Estrellas, explosiones y CRT
- Chiptune y SFX arcade
